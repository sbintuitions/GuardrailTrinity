# The Guardrail Trinity

Code for the paper **"The Guardrail Trinity: Procedural Safety Schemas, Reasoning
Chain Decomposition, and Dual-Mode Inference for LLM Guardrails"**, published at
[AACL-IJCNLP 2026](https://2026.aaclnet.org/) (the 5th Conference of the Asia-Pacific
Chapter of the Association for Computational Linguistics and the 15th International
Joint Conference on Natural Language Processing).

The Guardrail Trinity is a data-curation recipe for adaptive, dual-mode LLM safety
guardrails that combines procedural safety schemas, reasoning chain decomposition
with hard-negative supervision, and a hybrid fast/slow training blend.

> The code release is in preparation.
